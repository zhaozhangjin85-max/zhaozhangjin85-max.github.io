Verifiable LLM Agent Framework for EDA (gate-level netlist case study)

Team lead · 2026 CAD Contest at ICCAD · Problem A · Team cada1078

Honorable Mention Prize

Zhangjin Zhao · First author · Manuscript under review at DAC

CAD Contest Problem A casts EDA as a tool-augmented agent problem. Given a gate-level Verilog netlist and a sequence of natural-language intents on one evolving design (e.g., “Does every path from A to B pass through C?”, “Insert AND gates before all buffers matching a name pattern”), the agent must ground each intent to netlist entities and carry out structural analysis, transformation and constrained optimization with deterministic, verifiable behavior. I led a team that built a neuro-symbolic solution: the LLM serves as semantic parser and planner emitting schema-typed tool calls, while a deterministic execution layer over a persistent design state applies them under a propose–verify–commit protocol with formal equivalence checking and rollback.

Background, core work and outcome

BackgroundLetting an LLM operate EDA data, rather than only talk about it, pays off only if its results can be trusted, and netlists are a strict testbed because correctness is formally checkable. In Problem A, each test case supplies a flat gate-level Verilog netlist and a sequence of natural-language requests on one evolving design: analysis questions, transformations and constrained optimization. The contest provides no EDA tools, so each team defines its own netlist-level interface and drives it with GPT-4o-mini or Claude Haiku 4.5 (the expected framework is shown in the figure). Three properties make this hard: intents are underspecified and must be grounded to concrete netlist entities, requests arrive sequentially so errors compound through state, and fluent but unverified output is not acceptable.

Core workI led the team that built a neuro-symbolic agent in which the LLM decides what to do and deterministic code decides how the netlist changes. Language is mapped to 81 schema-typed tools (JSON-schema contracts, native function calling on both APIs) built from composable relational operators over netlist relations (filter, argmax, group, join). A stateful design session holds the before/after IR, structural constraints and cached analyses across requests, and a hybrid dispatcher routes each request through either a predefined operation path or LLM interpretation. Every edit follows propose–verify–commit: it is applied transactionally to a snapshot, checked by combinational equivalence checking (Yosys/ABC SAT miter) and structural-constraint checks, then committed or rolled back, and the result is returned to the agent as an observation.

OutcomeOn the hidden test set (100 unseen cases, 674 requests, netlists up to 213k gate/register instances), the agent scored 661.4 of 674 under the official case-wise best-of-two-LLM scoring and earned the Honorable Mention Prize. Because edits are verified before they are committed, a rejected edit does not carry errors into later requests. Operators, state and verifiers are pluggable, so the loop is designed to extend to other EDA tasks by adding domain tools and checkers; cross-domain transfer is future work and has not been measured.

Problem setter: Cadence Design Systems. Official category scores: 589/590 basic, 38/38 transformation, 34.42/46 optimization (661.4/674 in total), recomputed from official request-level scores. Equivalence checking is combinational only.

Multi-Conductor S-Parameter Prediction for PCB Signal Integrity

Prof. Quan Chen’s group, SUSTech · Industry collaborations: Xpeedic and OPPO

Zhangjin Zhao · Co-first author · Manuscript under review at DAC

A graph-based neural surrogate for electromagnetic extraction. The model maps a graph representation of coupled multi-conductor PCB interconnects, together with stack-up/material parameters and a frequency query, to complex multiport S-parameters (reflection, transmission and inter-line crosstalk). A single forward pass replaces repeated full-wave solves, enabling rapid signal-integrity design-space exploration.

Background, core work and outcome

BackgroundSignal-integrity analysis of high-speed PCB interconnects relies on S-parameters, which come from electromagnetic extraction. Exploring a design space needs many extractions, and commercial tools take hours for a DDR4 byte or three PCIe 5 differential pairs. A useful surrogate must stay accurate for coupled multi-conductor structures, where reflection, transmission and inter-line crosstalk have to be predicted together across a broad frequency band; this project targets 4–16 conductors.

Core workI develop graph-Transformer surrogates that map a routed PCB structure directly to its S-parameters, building on the group’s ISEDA 2025 SFormer. The layout becomes a graph of traces carrying geometry, connectivity and stack-up/material properties; a GRIT graph Transformer models geometric interaction and cross-trace coupling, with propagation-delay encodings and frequency-conditioned cross-attention so the model answers frequency queries. Port-pair readouts and local frequency refinement predict the real and imaginary parts of each response, and reciprocity reconstructs the full port matrix (8 ports for the four-conductor model). The figure shows the group’s earlier SFormer architecture, not the multi-conductor model; my contribution is the multi-conductor modeling and evaluation.

OutcomeOn held-out four-conductor layouts, predictions agree with Cadence PowerSI references to 0.128 dB mean magnitude error and 0.874° mean circular phase error, and a forward pass takes milliseconds, against hours for commercial extraction. The 4–16-conductor targets are ongoing research.

Benchmark: 358 held-out segment-only parallel-trace layouts (four conductors, eight ports), 36 unique port pairs, 100 native frequency points from 0.5 to 50 GHz, with Cadence PowerSI reference responses; means cover all layouts, port pairs and frequencies.

Group research foundation: ISEDA 2025

Data-Efficient Cross-Technology Analog IC Sizing with LoRA-Adapted Diffusion Transformer

Zhangjin Zhao · First author · Under review at DATE 2027

Cross-technology inverse design of analog circuits, formulated as conditional generative modeling. A specification-conditioned Diffusion Transformer learns a prior over sizing parameters on a source process and is adapted to a target process with parameter-efficient fine-tuning (LoRA) under data scarcity. A transferred surrogate ranks the generated candidates, so only a small subset reaches SPICE verification, forming a generate–screen–verify loop. I am first author; the manuscript is under review at DATE 2027.

Background, core work and outcome

BackgroundMigrating an analog design to a new process is expensive: a sizing model needs fresh simulation data for the target technology, and such data are scarce. Sizing is also an inverse, one-to-many problem, since the same performance specifications can be met by several parameter sets, which a model that predicts a single answer cannot represent. The goal is to carry what is learned on a source process to a new one with as little target-process data as possible.

Core workAs first author, I framed this as conditional generation and built a generate–screen–verify pipeline. A specification-conditioned Diffusion Transformer is pretrained on source-process designs to learn a transferable prior over sizing parameters, then adapted to the target process with LoRA while its backbone stays frozen. At inference, target specifications condition the generation of sizing candidates; a transferred multi-output MLP predicts their performance and ranks them, and only the top candidates go to SPICE for verification (Figure 1). To train and evaluate the approach, I automated multi-topology, multi-process dataset generation with OCEAN and Cadence Spectre.

OutcomeAcross three op-amp topologies (5T, two-stage, folded-cascode) and three process nodes (180/130/55 nm), the adapted model reaches under 2% mean relative error with 19.8–71.3% fewer target-process samples than full fine-tuning, and surrogate screening cuts SPICE evaluations by 80%. The manuscript is under review at DATE 2027.

ASTRI (Hong Kong), EDA Elite Challenge Problem 9. Protocol: five migration tasks, three seeds, learning-curve interpolation at <2% MRE over 10 circuit-performance metrics; screening keeps the top 20 of 100 candidates. Metrics include gain, CMRR, unity-gain frequency, phase margin, slew rate, power, input common-mode limits (min/max), and output-voltage limits (min/max).
